# Contribuir

Lee AGENTS.md y HANDOFF.md. Crea cambios pequeños con Conventional Commits. Para comportamiento, demuestra primero un test rojo y luego verde. Ejecuta todos los checks relevantes.

No añadas servicios remotos, telemetría, permisos, criptografía, dependencias o código copiado sin ADR/revisión de seguridad y licencia. No incluyas secretos, datos personales ni archivos de usuario.

Toda contribución debe actualizar documentación operativa si cambia estado, arquitectura, archivos, riesgos o próximos pasos.
