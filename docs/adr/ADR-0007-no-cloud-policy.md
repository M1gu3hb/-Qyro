# ADR-0007: Sin nube

- Estado: aceptada para desarrollo inicial
- Fecha: 2026-08-04

## Contexto

Privacidad/offline son promesa central.

## Decisión

No backend, relay, telemetría ni almacenamiento remoto.

## Alternativas

Relay obligatorio; cuentas.

## Consecuencias

Uso offline y superficie menor.

## Riesgos

NAT limita conexiones fuera de LAN, fuera del MVP.
