# Qyro

Qyro es una aplicación privada y multiplataforma para transferir archivos directamente entre dispositivos, sin cuentas, nube, anuncios ni telemetría.

> Estado: desarrollo inicial. El nombre, los identificadores y la licencia son provisionales hasta aprobación del propietario.
